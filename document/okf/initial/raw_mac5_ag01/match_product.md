# What it is

External table over AVRO files in `gs://file-raw-data/mac5_ag01/match_product/*.avro` (no partition columns, the whole glob is read). It is the raw landing copy of the `match_product` table from MAC5 for company `ag01`; nothing is cleaned or deduplicated here. Table meaning: Mapping of product barcodes to MAC5 stock codes.

Read by: [validated_mac5.match_product](/validated/validated_mac5/match_product.md).

# Grain and key

One row per source record in the files under the URI. No key is declared at this layer. The files are replaced or appended by the extract job, so the row set is the content of the files.

# Schema

| Column | Type | Description |
|---|---|---|
| `id` | INT64 | Row identifier of the mapping. |
| `barcode` | STRING | Product barcode (EAN-13). |
| `product_id` | STRING | MAC5 stock code mapped to the barcode. |
| `create_date` | STRING | Date and time the mapping was created. |

# How it is built

- Created by the Dataform operation `create_all_table_raw_mac5` (`definitions/initial/mac5/create_all_table_raw_mac5.sqlx`, tag `initial`) with `CREATE OR REPLACE EXTERNAL TABLE` (preceded by `DROP TABLE IF EXISTS`). It is a metadata object: no data is stored in BigQuery, every query reads the GCS files.
- Format `AVRO`, URI `gs://file-raw-data/mac5_ag01/match_product/*.avro`.
- Refresh: the extract job drops new files in the bucket; the external table sees them immediately. Dataform does not refresh it daily.
