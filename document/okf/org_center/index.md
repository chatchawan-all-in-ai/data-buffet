# Org Center

Organisation structure (units, members, people, links, customer portfolios, data-quality flags).

# Tables

* [org_center_customer_ta](org_center_customer_ta.md) - One row = one customer in the portfolio of one TA for a date range, from the MDS customer-to-TA portfolio master.
* [org_center_flags](org_center_flags.md) - One row = one data-quality problem found in the org-center tables (unit, member, person or link).
* [org_center_link](org_center_link.md) - One row = one promoter (PC) linked to one TA at one branch for a date range, from the MDS PC-to-TA assignment table.
* [org_center_member](org_center_member.md) - One row = one person holding one position at one unit for a date range (CEO, director, region manager, section manager, TA, or PC).
* [org_center_person](org_center_person.md) - One row = one person (across all companies) in the org center, with name, contact, companies, current positions and an active flag.
* [org_center_unit](org_center_unit.md) - One row = one organisation unit (company, division, region or section) of one company.
